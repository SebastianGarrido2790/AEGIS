## 5. Post-Hoc Immutability

`params.yaml` and the test data, and re-evaluates the gates against the live config;
any mismatch fails with exit code 1. Altering a frozen threshold after this run

inputs; it is not a signature and does not resist a deliberate re-sign of both sides.
